# VELA

**Erst kennenlernen, dann sehen.**

VELA ist eine Open-Source-Dating-App gegen oberflächliches Swipen. Profilbilder bleiben hinter einem Schleier verborgen und werden erst sichtbar, nachdem ihr ein paar echte Nachrichten ausgetauscht habt. Erst die Persönlichkeit, dann das Foto.

## Warum VELA?

- **Der Schleier:** Kein Urteil nach einem einzigen Foto. Bilder lösen sich erst nach einem echten Gespräch auf.
- **Open Source:** Der gesamte Code ist offen. Jede und jeder kann nachvollziehen, wie Matching und Datenschutz funktionieren, und mitbauen.
- **Ohne KI:** Keine Algorithmen, die dich bewerten. Menschen lesen Sätze, nicht Scores.
- **Datenschutz zuerst:** Transparent statt Blackbox.

## So entsteht die Resonanz

Die Prozentzahl „Resonanz“ auf jeder Karte ist eine feste, offene Formel, ohne KI:

```
Resonanz = 48 + 14 × (gemeinsame Werte) + (gleicher Orbit ? 26 : 6), begrenzt auf 46–96
```

Fotos, Aussehen oder Aktivität fließen nicht ein. In der App zeigt jedes Profil unter „So entsteht die Resonanz“ die eigene Rechnung. Der Code steht in [`src/lib/vela/data.ts`](src/lib/vela/data.ts).
